# mi-primer-pr

Repositorio de prueba para aprender a abrir Pull Requests con GitHub.

## ¿Qué es un Pull Request?

Un Pull Request (PR) es una propuesta de cambio en un repositorio. Permite revisar
el código antes de fusionarlo con la rama principal.

## Pasos para contribuir

1. Haz un fork del repositorio (o clónalo si tienes acceso directo)
2. Crea una rama nueva: `git checkout -b mi-mejora`
3. Realiza tus cambios y haz commit: `git commit -m "descripción del cambio"`
4. Sube la rama: `git push origin mi-mejora`
5. Abre un Pull Request desde GitHub
